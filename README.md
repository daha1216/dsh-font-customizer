# 🔤 dsh-font-customizer

> DeepSeek Harness（DSH）界面与代码字体定制插件。

一站式调整 Web 界面字体、代码等宽字体与正文字号，支持本机已装字体智能探测与全量扫描，配置持久化保存在宿主机。

---

## 📦 安装与更新

```sh
# 安装 / 更新
dsh plugin --profile web add github:daha1216/dsh-font-customizer
```

> 安装或更新后请重启 DSH Web 并刷新网页。设置入口位于 **设置 → 通用 → 字体（dsh-font-customizer）**。

---

## ✨ 核心特性

- **界面与代码字体分离**：独立配置全局界面字体栈（`--dsw-font-family`）与代码块等宽字体（`--ds-font-family-code`），即改即生效。
- **正文字号微调**：支持 12–17px 自由调节，无缝联动客户端内置主题服务。
- **本机字体探测与扫描**：智能探测预设字体安装状态（已装标注 ✓），支持一键调用本地字体 API 扫描系统全部已装字体。
- **常用字体预设与自定义**：内置思源黑体/宋体、霞鹜文楷、鸿蒙字体及 JetBrains Mono、Fira Code 等流行代码字体，亦支持手动填写任意 CSS 字体栈。
- **宿主机持久化**：配置原子写入本地存储，跨浏览器、多端设备自动同步，支持一键重置。
